# GitLantern

An open source desktop git client.

GitLantern is in early development.

## Download

Installers for Windows, macOS and Linux are on the [releases page](https://github.com/DanCommitsGit/gitlantern/releases).

## Build from source

You need Node.js 24 and git.

```bash
git clone https://github.com/DanCommitsGit/gitlantern.git
cd gitlantern
npm install
npm run build:win
```

On macOS or Linux, use `npm run build:mac` or `npm run build:linux` instead. The installer is written to `dist/`.

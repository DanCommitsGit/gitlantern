# Spell the product name GitLantern

Status: Accepted

## Context

The name is a compound of git and lantern. Written all lowercase, the seam is hidden and the name looks like a typo at the start of a sentence, which happens in the interface and the docs.

## Decision

Write GitLantern in prose, in the interface, in the window title and wordmark, and as the product name of the packaged app. Keep the lowercase `gitlantern` for identifiers: the package name, the repository, the executable name, the app ID and artifact file names.

## Consequences

Two spellings exist. The rule for choosing is that anything a person reads says GitLantern and anything a program matches on says `gitlantern`. Release notes already published keep the old spelling.

# Use real git terms in the UI

Status: Accepted

## Context

GitLantern teaches git by showing the real command behind each action. Friendly labels next to those commands would teach two vocabularies.

## Decision

Label actions with git's own words, such as Commit, Stash and Rebase, and explain them with plain-language hints on hover. There is no terminology setting.

## Consequences

Newcomers meet unfamiliar words straight away, so the hints have to carry the explanation.
